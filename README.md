# MindFlow · 免费在线思维导图 / 流程图 / 白板

一个类 GitMind 的在线思维导图网站，纯前端零构建 + Cloudflare Pages + Functions + D1，支持账号注册登录与云端存储。

**线上地址**：<https://gitmind-48x.pages.dev>

## 功能特性

### 三种编辑模式（同一 SVG 画布内核）
- 🧠 **思维导图**：顶部工具栏（参考 mind-map）——回退/前进、子节点（Tab）/ 同级节点（Enter）/ 删除节点、图片（插入节点，图上文下）、图标（24 个 emoji 快选）、超链接（蓝色「链」徽标可点击打开）、备注（橙色「注」徽标悬停查看）、关联线（L，任意两节点橙色虚线曲线）、整理布局；选中节点左侧样式面板——文字颜色 / 字号 S-XL / 加粗·斜体·下划线 / 背景色 / 边框颜色·宽度·样式 / 形状（圆角·矩形·下划线）；树状横向自动布局、父子自动连线、4 套主题配色一键换装、缩放平移
- 🔀 **流程图**：顶部工具栏（参考 mind-map）——回退/前进、选择（V）、矩形/圆角/判断/椭圆/平行四边形/文本、关联线（左键从起点拖到目标，自动吸附端口，松开即完成并自动回到选择工具）、图片、删除节点，快捷键 V / 1-7 / L，节点端口拖拽连线，箭头自适应方向
- 🎨 **自由白板**：类 Excalidraw 浮动工具栏——选择 / 抓手 / 画框（Frame）/ 矩形 / 菱形 / 圆形 / 箭头 / 直线（拖拽创建，Shift 吸附 45°）/ 画笔 / 文字 / 图片 / 橡皮 / 激光笔（轨迹自动淡出），「…」菜单支持嵌入网页（iframe 节点）、便签、清空白板，6 色描边色板，快捷键 1/V/H/F/2/3/4/5/6/7/8/9/0/K
- 🖌️ **图形属性面板**：使用图形 / 画笔工具或选中图形时，左侧浮动属性面板（类 Excalidraw）——描边色、背景色（含透明棋盘格）、描边宽度（细/中/粗）、边框样式（实线/虚线/点线）、线条风格（圆滑/手绘/随性，手绘为确定性抖动路径）、边角（圆角/直角）、透明度滑杆、图层排序（置顶/上移/下移/置底）；修改实时应用到选中图形，同时作为新建图形的默认值
- ✍️ **文字属性面板**：使用文字工具或选中文字节点时，专属面板——文字颜色、字体大小（S/M/L/XL）、字体（无衬线/衬线/代码）、样式（正常/斜体）、文本对齐（左/中/右）、透明度、图层排序；点击画布**任意位置（含已有图形上方任意图层）即在该点出现光标竖线等待输入**（Excalidraw 同款透明编辑区，节点宽度贴合内容、多行自动增高，空文本自动丢弃，用完自动回选择工具），双击再次编辑，样式实时生效并作为后续新建文字的默认值
- 📏 **直线自由变换**：直线 / 箭头选中后出现变换手柄——拖两端圆点改起点终点、拖中点圆点把直线弯曲为曲线（二次贝塞尔），细线加宽命中区更易点选
- 🔲 **框选多选（全模式）**：思维导图 / 流程图 / 白板的空白处左键拖拽即可框选多个元素（Shift 追加选择），选中后可整体拖动 / 删除；三模式均支持**长按右键拖拽平移画布**，也可用中键拖拽、Alt+左键拖拽或白板抓手工具
- 🔗 **关联线自由调节**：流程图 / 思维导图的关联线段选中后显示中点手柄，拖中点改变弯曲度（二次贝塞尔）；选中连线可在右侧样式面板调颜色 / 线宽 / 线型（实线·虚线·点线）/ 一键拉直 / 编辑文字标签
- 🪟 **右侧设置面板**：样式 / 设置工具栏仅在思维导图模式下展示，流程图与白板不显示

### 通用能力
- 👤 **账号体系**：邮箱注册 / 登录（PBKDF2 口令哈希 + HttpOnly Cookie 会话，`gm_sid`）
- ☁️ **云端存储**：Cloudflare D1（共享 `dev` 库，表前缀 `gm_`）+ R2 对象存储——导图内容优先存 R2（对象 Content-Type 统一为 `application/json; charset=utf-8`，⚠️ 必须用 `httpMetadata.contentType` 传参——R2 put 不支持 Blob 式 `{ type }` 选项，会被静默忽略导致对象无类型被当作 text/plain；key 格式 `maps/<用户ID>/<导图ID>.json`），`gm_maps.data` 置 NULL 不冗余；R2 不可用时自动回退 D1 `data` 列兜底，读取按 `r2_key` → 旧格式 key → D1 三级回退
- 💾 **保存状态与文件大小**：顶栏显示「已保存 09:39 · 12.3 KB」，浏览列表与分享页同样展示文件大小（`gm_maps.size` 落库）
- 🔄 **格式兼容**：自动识别并转换 simple-mind-map（mind-map 项目）格式的旧快照 / 导入文件（`layout/root/children` 树形 → 原生 `nodes` 平铺，`logicalStructure` 等布局名映射），云端加载即转换并回写自愈
- 📋 **模板库**：读书笔记 / 项目计划 / 会议纪要 / 知识梳理 / 请假流程 / 白板涂鸦
- 🔗 **分享链接**：一键生成公开只读页 `/share.html?id=<id>`
- 📤 **导入导出**：PNG / SVG / JSON 导出，JSON 导入（兼容 simple-mind-map 导出格式）
- 🛠 **增量迁移**：`scripts/migrate-r2-key.mjs`（补 `storage`/`r2_key`/`size` 列、`data` 放开为可 NULL、回填 size，幂等可重跑）；`scripts/fix-r2-content-type.mjs`（存量 R2 对象 Content-Type 统一刷为 `application/json; charset=utf-8`，幂等可重跑）；`scripts/deploy.mjs`（非交互部署）。脚本配置统一走 **环境变量 / 项目根 `.env`**（见 `scripts/config.mjs`，模板 `.env.example`，源码零硬编码）
- 📝 **大纲模式**：文字大纲与脑图双向转换
- 🖱️ **右键菜单（三模式通用）**：
  - 🧠 **思维导图**：回到根节点 / 展开全部 / 收起全部 / 展开到 N 级 / 一键整理布局 / 适应画布 / 禅模式 / 去除自定义样式 / 复制到剪贴板（PNG·SVG·JSON 子菜单）；节点折叠徽标（±）点击展开收起子树
  - 🔀 **流程图**：撤销 / 在此粘贴 / 复制为图像 / 复制为 SVG / 清除默认风格 / 全选 / 选择所有顶点 / 选择所有边线 / 编辑连线样式
  - 🎨 **白板**：剪切 / 粘贴 / 复制 / 复制为 PNG / 复制为 SVG / 复制文本 / 拷贝样式 / 粘贴样式 / 编辑 / 锁定·解锁 / 显示网格 / 层级（置顶·上移·下移·置底）/ 水平·垂直翻转 / 创建副本 / 全部锁定·解锁 / 删除 / 详细统计；支持组合（Group）与解组、组内联动拖拽
- 🪟 **交互细节**：删除文档二次确认弹框（珊瑚橙确认按钮）；详细统计信息右上悬浮面板（元素/宽高/画布与总存储）；右下角「?」打开两栏快捷键弹框；左下角缩放（−/100%/+，点百分比重置）与撤销重做控制条；右侧说明栏可一键收起/展开（记忆偏好）
- ⌨️ **快捷键**：Tab 加子节点 · Enter 加兄弟 · Delete/Del 删除 · Ctrl/⌘+S 保存 · 滚轮缩放 · 拖空白平移；完整列表见文末「快捷键速查」

## 数据模型

- `gm_maps.data` 存整张图 JSON：`{ type, nodes[], edges[], strokes[], view }`
  - `nodes[]`：`{ id, text, x, y, shape, color, textColor, stroke, fontSize, parentId }`
  - 脑图连线不落库，渲染时按 `parentId` 实时派生；流程图连线存 `edges[]`

## 本地开发

零构建，任意静态服务器即可预览前端（API 需部署后可用）：

```bash
python -m http.server 8787
```

## 部署（Cloudflare Pages + D1）

脚本配置统一读环境变量或项目根 `.env`（不入库；先复制 `.env.example` 填写）：
`CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID` / `D1_DATABASE_ID`，可选 `R2_BUCKET`、`WRANGLER_BIN`（wrangler 入口，留空走 PATH）。

```bash
# 1. 建表（幂等）
node scripts/init-d1.mjs

# 2. 部署
node scripts/deploy.mjs
```

wrangler.toml 绑定：D1 → 共享 `dev` 库（database_name=dev）。
